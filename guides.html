🦢 Desktop Goose

Официальный источник: samperson.itch.io/desktop-goose

Как запустить

  1. Скачай ZIP с официальной страницы itch.io.
  2. Распакуй папку в любое удобное место.
  3. Запусти GooseDesktop.exe (Windows) или приложение (macOS).
  4. Чтобы выйти — зажми клавишу Esc на несколько секунд.

Как поменять мемы и картинки

  1. Полностью закрой гуся.
  2. Открой папку → перейди в Assets/Images/Memes.
  3. Удали ненужные изображения.
  4. Положи свои PNG / JPG / GIF файлы в эту папку.
  5. Запусти гуся заново — он будет использовать твои картинки.

Как поменять тексты в блокноте

  1. Перейди в Assets/Text/NotepadMessages.
  2. Каждый .txt файл — это одно сообщение, которое гусь может показать.
  3. Отредактируй существующие файлы или создай новые .txt со своими текстами.
  4. Сохрани и перезапусти гуся.

Как изменить поведение и цвета (config.ini)

Открой файл config.ini блокнотом. Полезные параметры:

SilenceSounds=True          # отключить звуки
Task_CanAttackMouse=False   # запретить воровать курсор
AttackRandomly=True         # случайные атаки
EnableMods=True             # включить моды
UseCustomColors=True
GooseDefaultWhite=#ffffff
GooseDefaultOrange=#ffa500
GooseDefaultOutline=#d3d3d3
MinWanderingTimeSeconds=20
MaxWanderingTimeSeconds=40

После изменений сохрани файл и перезапусти программу.

Важно: не распространяй изменённые версии Desktop Goose как свою работу. Оригинальный создатель — samperson. Поддержи его на itch.io.

🦆 Desktop Duck

Фанатская версия Desktop Goose от Darquenn

Как запустить

  1. Скачай с официальной страницы itch.io.
  2. Распакуй и запусти исполняемый файл.
  3. Выход такой же, как у гуся — зажать Esc.

Настройка

Структура почти идентична Desktop Goose. Ищи папки с картинками и текстами и заменяй их своими файлами. Всегда закрывай программу перед редактированием.

🐑 eSheep / Desktop Pet

Открытая переработка классики 1995 года

Как запустить

  1. Скачай портативный EXE или установи из Microsoft Store.
  2. Запусти — овца появится на рабочем столе.
  3. Правый клик по иконке в трее — добавить ещё овец, сменить питомца.

Как создать своё животное

Через XML + спрайт-лист. Подробности и редактор: adrianotiger.github.io/desktopPet

Общие советы

  • Делай резервную копию перед изменениями.
  • Закрывай питомца перед редактированием файлов.
  • Уважай оригинальных авторов.
