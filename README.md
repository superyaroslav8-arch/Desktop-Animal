# Desktop Animal

Кураторский сборник лучших десктопных животных-питомцев.

Сайт содержит описания, официальные ссылки на скачивание и подробные инструкции по настройке (замена картинок, текстов, конфигов) на русском языке.

**Сайт:** открой `index.html`
